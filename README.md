# Студия автомонтажа Reels

Казахский + русский, Whisper large-v3, ffmpeg. Подробности — в `CLAUDE.md`.

```bash
git clone <этот репозиторий> reels-studio && cd reels-studio
bash setup.sh                      # Homebrew, ffmpeg, Whisper (~3 ГБ модель)
./рилс Исходники/видео.mp4         # монтаж; панель: http://localhost:8765
```
