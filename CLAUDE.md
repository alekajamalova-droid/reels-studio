# Студия автомонтажа Reels

Отвечай пользователю по-русски и коротко. Если нужно разрешение (установка, сеть, удаление) — спрашивай.

## Фраза-триггер
**«смонтируй рилс <файл>»** → делай так:
1. Если файла нет в `Исходники/` — попроси положить его туда (или указать путь).
2. `.venv/bin/python studio/reels.py prepare "<файл>"` — Расшифровка + Сценарист (~1–2 мин на минуту видео на CPU).
3. **Покажи пользователю расшифровку** (`work/<проект>/transcript.txt`) целиком, включая строку `ХУК:`. Спроси, что исправить.
4. Внеси правки ТОЛЬКО в текст после `]` (и в строку `ХУК:`). Таймкоды в скобках не трогай.
   Если число слов в строке не меняется — тайминги слов сохранятся точно; если меняется — время делится по длине слов.
   Удалённая строка = фраза вырезается из ролика.
5. По желанию — превью: `.venv/bin/python studio/reels.py preview <проект>` (540x960, `work/<проект>/preview.mp4`).
6. После «ок/готово» — `.venv/bin/python studio/reels.py render <проект>` → `Готово/<проект>_reels.mp4`.
7. Сообщи итог: длительность до/после, LUFS, путь к файлу.

Имя проекта = имя файла без расширения (не-буквы заменены на `_`).

## Команды
- `bash setup.sh` — установка с нуля (Mac: Homebrew, ffmpeg с libass, Python 3.12, venv, модель Whisper).
- `./рилс <файл>` (или `./reels <файл>`) — всё одной командой в терминале: панель + расшифровка → пауза на проверку → рендер. `--auto` — без паузы.
- `.venv/bin/python studio/panel.py --open` — веб-панель http://localhost:8765
  (исходник, превью, расшифровка, шаги агентов, кнопки «Сохранить», «Превью», «Готово», загрузка видео).

## Агенты (шаги) — `studio/reels.py`
1. **Расшифровка** — faster-whisper `large-v3`, `language=kk`, таймкоды по словам, подсказка `whisper_prompt` (казахский + русские слова + «ээ, эм», чтобы Whisper записывал паразиты). Звук декодируется через ffmpeg в numpy (не через PyAV).
2. **Сценарист** — убирает паразиты (`filler_regex`: ээ, эм, ммм, ыы, әә…), повторы подряд (1–4 слова), неудачные дубли (фраза начинается как следующая), делит на фразы (≤9 слов), хук = первое предложение без приветствия (≤7 слов).
3. **Субтитры** — ASS: по 1 слову, Inter Bold 96, белые, чёрная обводка 6, по центру снизу (отступ 420 px — выше интерфейса Instagram), без смайликов и без точек/запятых в конце. Хук: Inter Black 104, ЗАГЛАВНЫЕ, сверху, 0–3 сек.
4. **Звук** — loudnorm 2 прохода → −14 LUFS, true peak −1 dBTP; после рендера контроль, при отклонении >0.5 LU докрутка с лимитером.
5. **Рендер** — вырезаются паузы >0.25 с (запас 0.08 с вокруг слов, микро-фейды на стыках), кроп по центру в 1080x1920, 30 fps, H.264 CRF 18, AAC 192k 48 кГц, faststart.

## Настройки — `studio/config.json`
Модель, язык, паузы, громкость, размеры/шрифты субтитров и хука, слов на экране (`subs.words_per_caption`), ЗАГЛАВНЫЕ в субтитрах (`subs.uppercase`). Шрифты лежат в `studio/fonts` (Inter — поддерживает ә ғ қ ң ө ұ ү һ і).

## Папки
- `Исходники/` — сырые видео · `Готово/` — готовые рилсы
- `work/<проект>/` — `words.json` (сырые слова Whisper), `phrases.json`, `transcript.txt` (редактируемая расшифровка), `subs.ass`, `cuts.json`, `preview.mp4`, `state.json` (статусы агентов для панели)
- `models/large-v3/` — модель Whisper (~3 ГБ), `.venv/` — Python-окружение

## Важно
- Если `ffmpeg -filters` не содержит ` ass ` — субтитры не отрисуются; на Mac поставить `brew install ffmpeg-full`.
- Модель качается с huggingface.co (+ CDN `us.aws.cdn.hf.co`); в облачной сессии эти хосты уже разрешены в окружении.
- Казахский у Whisper иногда пишет русские слова казахскими буквами — поэтому шаг проверки расшифровки обязателен.
- Не удаляй папки `Готово/` и `Исходники/` целиком.
